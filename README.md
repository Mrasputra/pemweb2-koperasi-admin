# Admin Panel — Sistem Informasi Koperasi Simpan Pinjam

Tugas Mandiri Mata Kuliah **Pemrograman Web 2** (Client-Side Programming) —
Front-end Admin Panel untuk sistem informasi koperasi simpan pinjam.
Client-side only (HTML5, CSS3, JavaScript vanilla), tanpa back-end —
data memakai mock data & `sessionStorage`.

## 🎨 Style UI
Glassmorphism — dark navy gradient background, panel kaca blur, aksen cyan/teal.

## 🗂️ Struktur Halaman
| File | Deskripsi |
|---|---|
| `layout.html` | Template dasar (sidebar, header, content, footer) — Milestone 2 |
| `dashboard.html` | Ringkasan KPI + grafik (Chart.js) |
| `anggota.html` | Tabel Data Master Anggota (Tambah/Edit/Hapus) |
| `form-anggota.html` | Form input/edit anggota dengan validasi JS |
| `simpanan.html` | Tabel transaksi simpanan |
| `pinjaman.html` | Tabel transaksi pinjaman + status angsuran |
| `laporan.html` | Rekap bulanan siap cetak |
| `style.css` | Style bersama seluruh halaman |
| `script.js` | Interaktivitas: sidebar toggle, modal konfirmasi, validasi form, CRUD mock data |

## 📄 Dokumen Perencanaan
Lihat [`PERANCANGAN.md`](./PERANCANGAN.md) untuk hirarki menu, ER-D, dan
Design System.

## ▶️ Menjalankan
Buka `dashboard.html` langsung di browser — tidak perlu server atau instalasi.
